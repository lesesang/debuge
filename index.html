알아둘 것

기존 사이트: 실제 난수 개수와 준비한 값의 개수가 같을 때만 지정값을 사용합니다.
기존 사이트: 불일치·오류·코인 다이스는 준비값을 버리고 원래 랜덤으로 처리합니다.
bbs2 일반 다이스: 서버에서 무작위로 결정하므로 미리보기와 실제 게시 결과가 다를 수 있습니다.
bbs2 모의 결과: 원하는 숫자를 원래 다이스 범위와 함께 외부 도구에서 표시하고 복사합니다. 실제 게시판의 댓글이나 다이스 결과는 바꾸지 않으며, 출력에 모의 결과임을 명시합니다.
bbs2 고정 다이스: 최소값과 최대값을 입력한 결과로 같게 지정합니다. 예: [dice 37 37]. 게시물에 [37~37] 범위가 그대로 표시되며 일반적인 1~100 무작위 굴림이 아닙니다.
bbs2 관리자 편집: 게시판 관리자 권한으로 자신이 작성한 테스트 댓글을 사후 수정하는 방식입니다. 원래 범위는 유지하지만 실제 추첨 결과가 아니므로 일반적인 공정한 주사위 굴림으로 취급하면 안 됩니다. 일반 계정으로는 사용할 수 없습니다.
기존 사이트의 Console 테스트는 끝나면 자동 초기화됩니다. 수동 중단: window.__diceTestRestore()
