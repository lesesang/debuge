Dice Random Tester

댓글 다이스의 난수 결과를 지정해서 재현하는 테스트 도구입니다.

① 테스트 값 입력

왼쪽은 굴릴 다이스, 오른쪽은 나오게 할 결과입니다. 같은 줄끼리 대응합니다.

다이스

NdM · 최소값 NdMmK · 중복 없음 u

결과

2d100u → 40,80

② 생성된 테스트 코드

아래 코드를 복사해 대상 사이트의 DevTools Console에서 실행하세요.

아직 생성된 코드가 없습니다.

③ 사용법

입력다이스 + 결과
생성코드 만들기
실행Console
확인댓글 결과
핵심: 코드는 먼저 실제 난수 개수를 확인한 뒤, 준비한 개수와 정확히 같을 때만 테스트값을 사용합니다.

④ 안전 동작

개수 일치: 테스트값으로 실행 → 성공 → 자동 초기화.
개수 부족/초과: 테스트값을 전부 폐기 → 전체를 기본 랜덤으로 재실행 → 초기화.
오류: 테스트를 폐기하고 원래 랜덤으로 복구합니다.
수동 초기화: window.__diceTestRestore()

⑤ 참고

코인과 s 기능은 지원하지 않습니다.
SJCL: sjcl.encrypt() 내부 난수는 테스트하지 않고 원래 난수를 사용합니다.
범위: 현재 브라우저의 현재 페이지에만 적용됩니다.
