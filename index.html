Dice Random Tester

다이스 계산용 난수만 원하는 값으로 바꿔 실제 결과를 재현합니다.

① 다이스 설정 굴리는 값

한 줄에 하나씩 입력합니다.

지원: NdM, NdMmK, 끝에 u

② 원하는 결과 나올 값

각 줄의 결과 개수는 다이스 개수와 같아야 합니다.

예: 2d100u → 40,80

생성된 테스트 코드

대상 페이지의 DevTools Console에 붙여넣습니다.

아직 생성된 코드가 없습니다.

사용법

1. 다이스 설정을 입력합니다. 예: 2d100u
2. 원하는 결과를 같은 순서로 입력합니다. 예: 40,80
3. 코드 생성 → 대상 페이지 Console에 붙여넣고 댓글을 등록합니다.
4. 성공·오류·예상 개수 불일치·수동 초기화 모두 테스트 패치를 즉시 원상복구하고 테스트 값을 폐기합니다.
5. 예상보다 많은 난수가 필요하면 부족한 부분은 원래 랜덤으로 처리하고 테스트를 즉시 실패 종료합니다. 예상보다 적으면 테스트를 실패 종료합니다.
난수 처리: 다이스 계산에는 지정값을 사용하고 sjcl.encrypt() 내부에서는 원래 Math.random()을 사용합니다.
잘못된 입력: 다이스 형식·범위·결과 개수가 맞지 않으면 테스트 코드를 만들지 않습니다.
