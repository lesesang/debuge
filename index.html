Dice Random Tester

원하는 다이스 결과를 지정하고, 대상 페이지에서 실제 다이스 계산만 원하는 값으로 재현합니다.

① 다이스 설정 굴리는 값

한 줄에 하나씩 입력합니다. 아래 결과와 같은 순서로 대응합니다.

지원: NdM, NdMmK, 끝에 u

② 원하는 결과 나와야 하는 값

각 줄의 결과 개수는 해당 다이스의 개수와 같아야 합니다.

예: 2d100u → 40,80

생성된 테스트 코드

이 코드를 대상 페이지의 DevTools Console에 붙여넣으면 적용됩니다.

아직 생성된 코드가 없습니다.

사용법

1. 다이스 설정
2d100u처럼 실제 댓글에 넣을 다이스 문법을 입력합니다.
2. 원하는 결과
40,80처럼 실제로 나오게 할 값을 같은 줄에 입력합니다.
3. 코드 생성 → 대상 페이지 Console에 붙여넣기
그 뒤 댓글을 등록하면 지정한 순서대로 결과가 나옵니다.
난수 처리
다이스 계산은 테스트 값, sjcl.encrypt()는 원래 난수를 사용합니다. Error().stack으로 파일명이나 함수명을 추측하지 않습니다.
테스트 종료
window.__diceTestRestore()를 실행하면 패치한 함수와 테스트 상태를 전부 원래대로 복구합니다.
