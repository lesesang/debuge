② 생성된 코드

③ 사용법

댓글을 먼저 써도, 코드를 먼저 실행해도 됩니다.
등록할 때 실제 필요한 다이스 난수 개수를 먼저 확인합니다.
준비한 값 수와 실제 다이스 난수 수가 정확히 같을 때만 테스트값을 적용합니다.
개수가 다르거나 지원하지 않는 난수가 섞이면 테스트값을 사용하지 않고 기본 랜덤으로 한 번 다시 실행합니다.

④ 안전 동작

일반 문장과 색상·크기·글꼴 같은 서식은 건드리지 않습니다.
sjcl.encrypt() 내부 난수는 테스트 대상에서 제외하고 원래 랜덤을 사용합니다.
코인 다이스는 지원하지 않으며, 발견되면 테스트하지 않고 기본 랜덤으로 실행합니다.
성공·실패·오류·수동 중단 후에는 테스트 패치를 제거합니다.
수동 중단: window.__diceTestRestore()
