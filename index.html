Dice Random Tester

다이스 결과를 직접 지정해서 댓글 다이스 계산을 재현하는 테스트 도구입니다.

빠른 사용법

1. 입력다이스 + 결과
2. 생성테스트 코드 만들기
3. 실행대상 페이지 Console
4. 확인댓글 등록 결과
핵심: 왼쪽에는 어떤 다이스를 굴릴지, 오른쪽에는 그 다이스에서 나오게 할 값을 같은 줄에 적습니다.

① 다이스 설정 굴리는 값

한 줄에 다이스 하나를 입력합니다.

기본: NdM · 최소값: NdMmK · 중복 없음: 끝에 u

② 원하는 결과 나올 값

왼쪽과 같은 줄에 결과를 입력합니다. 여러 개면 쉼표로 구분합니다.

예: 2d100u → 40,80

입력 예시

일반 다이스
1d100 → 73
여러 개
2d100 → 40,80
최소값 지정
3d20m5 → 7,12,20
중복 없이
3d20u → 3,11,18
같은 값이 두 번 나오면 입력 오류입니다.

실행하기

1. 위 두 칸을 입력합니다.
2. 테스트 코드 생성을 누릅니다.
3. 코드 복사를 누릅니다.
4. 테스트할 사이트의 개발자 도구(Console)를 엽니다.
5. 복사한 코드를 Console에 붙여넣고 실행합니다.
6. Console에 적용 완료가 나오면 댓글을 등록합니다.
7. 결과를 확인합니다. 정상적으로 끝나면 테스트는 자동으로 초기화됩니다.

테스트 상태

정상: 준비한 난수를 모두 사용하면 성공하고 즉시 원래 상태로 돌아갑니다.
난수가 부족함: 준비한 값보다 적게 필요하면 테스트는 실패하고 남은 값은 폐기됩니다.
난수가 더 필요함: 준비한 값보다 많이 필요하면 초과분은 원래 랜덤으로 처리되고 테스트는 실패 후 초기화됩니다.
오류: 실행 중 오류가 발생해도 테스트값을 폐기하고 원래 상태로 복구합니다.
수동 초기화: 문제가 생겼거나 즉시 원상복구하고 싶으면 Console에서 window.__diceTestRestore()를 실행합니다.

중요한 점

테스트를 안 하면?
이 도구가 만든 코드를 실행하지 않는 한 대상 페이지의 난수에는 아무 영향이 없습니다.
다른 사람에게 영향이 있나?
없습니다. 이 코드는 현재 내 브라우저의 현재 페이지에서만 동작합니다. 서버의 다른 사용자에게 코드를 적용하는 방식이 아닙니다.
SJCL 암호화는?
sjcl.encrypt() 안에서는 원래 Math.random()을 사용하도록 분리되어 있습니다. 테스트값은 다이스 계산 쪽에서만 사용합니다.
입력이 잘못되면?
코드를 만들기 전에 형식, 범위, 다이스 개수와 결과 개수를 검사합니다. 문제가 있으면 테스트 코드를 생성하지 않습니다.

생성된 테스트 코드

생성된 코드는 대상 페이지의 DevTools Console에서 실행합니다.

아직 생성된 코드가 없습니다.
