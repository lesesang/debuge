Dice Random Tester

원하는 다이스 결과를 지정하고, submitComment()에서 사용할 테스트 코드를 생성합니다.

① 다이스 설정 굴리는 값

한 줄에 하나씩 입력합니다. 순서대로 오른쪽 결과와 대응합니다.

지원: NdM, NdMmK, 끝에 u / s

② 원하는 결과 나와야 하는 값

각 줄의 결과 개수는 해당 다이스의 개수와 같아야 합니다.

예: 2d100u → 40,80

생성된 테스트 코드

이 코드를 대상 페이지의 DevTools Console에 붙여넣으면 적용됩니다.

아직 생성된 코드가 없습니다.

사용법

1. 다이스 설정
2d100u처럼 실제 댓글에 넣을 다이스 문법을 입력합니다.
2. 원하는 결과
위 설정과 같은 줄에 대응하도록 40,80처럼 기대 결과를 입력합니다.
3. 코드 생성 → 대상 페이지 Console에 붙여넣기
그 다음 실제로 댓글을 등록하면 지정한 순서대로 다이스 결과가 나오도록 테스트됩니다.
sjcl 암호화 난수
다이스 계산용 난수만 지정값으로 바꿉니다. sjcl.js가 암호화 과정에서 사용하는 난수는 원래 Math.random()을 그대로 사용하므로, 암호화 때문에 테스트 값이 소비되지 않습니다.
테스트 종료
생성된 코드에는 복구 함수가 포함되어 있습니다. Console에서 window.__diceTestRestore()를 실행하면 원래 난수로 되돌아갑니다.
