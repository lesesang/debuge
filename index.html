Dice Random Tester

댓글의 다이스 난수를 지정한 값으로 재현하는 테스트 도구입니다.

① 입력

같은 줄의 다이스와 결과가 1:1로 대응합니다.

다이스

NdM · 최소값 NdMmK · 중복 없음 u

결과

2d100u → 40,80

② 테스트 코드

생성된 코드를 대상 사이트 DevTools Console에 붙여넣고 실행하세요.

아직 생성된 코드가 없습니다.

③ 사용법

1. 댓글을 먼저 써도 되고, 코드를 먼저 실행해도 됩니다.
2. 댓글 등록 버튼을 누르면 먼저 실제 난수 개수를 확인합니다.
3. 준비한 값의 개수와 실제 필요한 난수 개수가 정확히 같을 때만 테스트합니다.
개수 불일치 또는 오류: 입력을 복원하고 테스트를 버린 뒤, 원래 랜덤으로 한 번만 다시 실행합니다.

④ 안전 동작

일반 문장/서식: 다이스가 아닌 글, 색상, 크기, 글꼴 등은 테스트값 입력과 무관하게 그대로 둡니다.
SJCL: sjcl.encrypt() 안에서 필요한 난수는 항상 원래 Math.random을 사용합니다.
정상 완료: 테스트가 끝나면 패치와 테스트값을 즉시 제거합니다.
수동 초기화: window.__diceTestRestore()
