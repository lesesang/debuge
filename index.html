Dice Random Tester

다이스 결과를 직접 지정해서 댓글 다이스 계산을 재현하는 테스트 도구입니다.

빠른 사용법

1. 입력다이스 + 결과
2. 생성테스트 코드 만들기
3. 실행대상 페이지 Console
4. 확인댓글 등록 결과
핵심: 왼쪽에는 어떤 다이스를 굴릴지, 오른쪽에는 그 다이스에서 나오게 할 값을 같은 줄에 적습니다.

① 다이스 설정 굴리는 값

한 줄에 다이스 하나를 입력합니다.

기본: NdM · 최소값: NdMmK · 중복 없음: 끝에 u

② 원하는 결과 나올 값

왼쪽과 같은 줄에 결과를 입력합니다. 여러 개면 쉼표로 구분합니다.

예: 2d100u → 40,80

입력 예시

일반: 1d100 → 73
여러 개: 2d100 → 40,80
최소값: 3d20m5 → 7,12,20
중복 없음: 3d20u → 3,11,18

실행하기

1. 다이스와 결과를 입력합니다.
2. 테스트 코드를 생성하고 복사합니다.
3. 대상 사이트의 DevTools Console에서 실행합니다.
4. 적용 완료가 나오면 댓글을 등록합니다.
5. 결과를 확인합니다.

테스트 상태

개수 정확히 일치: 준비한 테스트값을 사용하고 성공 후 자동 초기화합니다.
개수 부족 또는 초과: 테스트값은 전부 폐기하고 전체를 기본 랜덤으로 다시 실행합니다. 테스트는 실패하고 초기화됩니다.
오류: 테스트를 폐기하고 원래 랜덤으로 복구합니다.
수동 초기화: Console에서 window.__diceTestRestore()를 실행하면 즉시 원상복구합니다.

중요한 점

테스트를 안 하면? 생성한 코드를 대상 페이지에서 실행하지 않는 한 아무 영향이 없습니다.
다른 사용자에게 영향? 없습니다. 현재 브라우저의 현재 페이지에서만 동작합니다.
SJCL: sjcl.encrypt() 안의 난수는 테스트 대상에서 제외하고 원래 Math.random()을 사용합니다.
입력 오류: 생성 단계에서 형식, 범위, 개수, 중복을 검사합니다.

생성된 테스트 코드

생성된 코드를 대상 페이지의 DevTools Console에서 실행합니다.

아직 생성된 코드가 없습니다.
