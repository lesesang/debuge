Dice Random Tester

댓글 다이스 결과를 지정해서 재현하는 테스트 도구입니다.

① 입력

같은 줄의 다이스와 결과가 서로 대응합니다.

다이스

NdM · 최소값 NdMmK · 중복 없음 u

결과

예: 2d100u → 40,80

② 테스트 코드

생성된 코드를 대상 사이트의 DevTools Console에서 실행하세요.

아직 생성된 코드가 없습니다.

③ 사용법

1. 댓글을 먼저 작성하거나 코드를 먼저 실행합니다.
2. 코드가 적용된 상태에서 댓글 등록 버튼을 누릅니다.
3. 실제 난수 개수가 정확히 맞으면 지정한 결과로 등록됩니다.
개수 불일치: 테스트 등록은 막고, 입력을 복원한 뒤 기본 랜덤으로 한 번만 등록합니다.

④ 자동 복구

정상 완료: 등록 후 테스트 기능을 자동으로 제거합니다.
오류: 테스트값과 패치를 폐기하고 원래 랜덤으로 복구합니다.
SJCL: sjcl.encrypt() 내부 난수는 원래 난수를 사용합니다.
수동: window.__diceTestRestore()
